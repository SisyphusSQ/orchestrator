# Issues and security reports

Report reproducible bugs and documentation gaps on the [SisyphusSQ/orchestrator Issues page](https://github.com/SisyphusSQ/orchestrator/issues).

Include the exact revision, server/client versions, deployment mode, redacted configuration fields, expected behavior, actual behavior, and the narrowest safe reproduction. Do not attach passwords, access tokens, private keys, authorization headers, full production topology exports, or unredacted logs.

For a suspected vulnerability, avoid publishing exploitable details until the repository maintainers provide a coordinated reporting path.
